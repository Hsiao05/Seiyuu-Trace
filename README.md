# 声迹（Seiyuu-Trace）

声迹是一个基于 Bangumi 数据的动画角色/声优统计网站。用户可以通过导入自己的 Bangumi 动画收藏，快速整理已经看过的作品，并统计自己听过哪些声优、看过哪些角色、最熟悉哪些声音。

## 功能

- 根据 Bangumi UID 导入已完成收藏的动画片单（可选已看动画/全部收藏动画）
- 按作品 ID 批量导入动画
- 通过 Bangumi API 搜索并添加作品和人物
- 导入时显示读取进度，并支持取消
- 统计看过的动画数量、听过的声优数量和角色记录数量
- 提供加权排行和无权排行两种统计方式
- 支持查看每位声优对应的作品和角色明细
- 支持跳转到 Bangumi 对应的声优、作品和角色页面
- 支持生成一览式角色库、声优库
- 可以在片目库方便增删
- 提供“声迹颁奖礼”总结页，展示总览数据和排名回顾
- 提供“生日日历”页面，月历/全年总表展示角色和声优的生日
- 支持日语/罗马音/英语/简中搜索动画或人物
- 兼容桌面端和移动端浏览

## 体验地址

使用前请先确保自己的网络环境可以访问 Bangumi / Bangumi API。

### v2 修复与更新内容

- 角色分类现在仅依据 Bangumi 的 relation 字段，不再使用角色 type。
- 旧缓存首次打开时会自动重新抓取角色关系并修正分类。
- 本地搜索与 Bangumi 搜索均支持简体中文名，同时保留原名匹配和显示。
- UID 导入新增“已看过 / 全部列表”选择；全部列表包含所有动画收藏状态。

### v3 修复与更新内容

- 新增“生日日历”、“角色库”和“声优库”。
- 生日日历：月历默认显示当前月份，支持前后切换、滑动换月、返回今天。日期圆点区分角色与声优，点击后打开生日抽屉。全年生日列表按月、日排序，可筛选角色或声优。
- 角色库：展示原名、简体中文名、假名、罗马音、英文名、作品、配音、生日、性别、血型、身高及 Bangumi 全部资料。支持按角色类型、性别、作品筛选。
- 声优库：支持完整资料、性别/作品筛选、多语言搜索，以及声优 ID 或 person 页面链接手动导入。
- 片目库：改为独立页面，支持多语言搜索、ID 添加、API 搜索添加和即时删除。删除作品会同步清理相关角色、声优、日历和排行数据。
- 搜索：支持日文、假名、罗马音、英文和简体中文。
- 优化：首次导入仅加载作品基础信息、角色关系，以及角色/声优的基础身份与生日。完整角色库、声优库分别按需加载并独立缓存。作品详情改为进入片目库或执行搜索时才加载，进一步减少首次请求。
- 显示优化：声优统计改用原名，日语名标注假名，下方显示简体中文名和罗马音。
- 修复：修复了手机端长作品名筛选器造成的横向溢出。
